# Экраны

[🇬🇧 English](displays.en.md) · [Руководство](README.md)

Страница «Экраны» показывает все дисплеи, которые знает Windows, и позволяет включить или выключить любой из них
галочкой — не заходя в параметры системы. На «Главной» на неё ведёт кнопка **«Активные экраны»**.

## Что в списке

| Столбец | Что показывает |
|---|---|
| Экран | как монитор назван в параметрах экрана Windows |
| Разрешение | разрешение и частота обновления включённого экрана; у выключенного — прочерк |
| Разъём | HDMI, DisplayPort, DVI и так далее |
| Видеокарта | карта, которая держит этот экран |
| Примечание | «основной», «включён» с именем вида `\\.\DISPLAY1` или «выключен в Windows» |

Галочка в строке — это и есть состояние экрана. Снимите её, и Windows перестанет держать для этого экрана рабочий
стол; поставьте — вернёт. Список перечитывается при каждом заходе на страницу и после каждого переключения, поэтому
показывает то, что есть сейчас, а не то, что было при запуске программы.

Строка внизу считает включённые экраны. Если рабочий стол собирают две видеокарты, там же появится напоминание про
«Отключение MPO» на странице [«Скрипты»](scripts.md): рывки курсора при переходе между экранами лечит именно он.

## Зачем выключать экран, который и так выключен

Выключение здесь **программное**: перестаёт быть активным путь «видеокарта → монитор», кабель остаётся в разъёме.
Это нужно, потому что телевизор, выключенный пультом, уходит в дежурный режим, но линию HPD держит поднятой. Windows
не видит отключения и продолжает держать для телевизора поверхность рабочего стола: видеокарта композитит экран,
которого никто не видит, а на смешанных частотах это ещё и удерживает память карты на высокой частоте.

Обратно экран возвращается той же галочкой. Если телевизор к этому моменту выключен совсем (вынут кабель), строка
из списка пропадёт — и появится снова, когда Windows его увидит.

## Чего страница не сделает

- **Последний включённый экран** выключить нельзя: рабочий стол остался бы без изображения.
- **Основной экран** выключить нельзя: Windows перенесла бы его сама, и неизвестно куда. Сначала назначьте основным
  другой экран в параметрах Windows.

В обоих случаях галочка вернётся на место, а причина появится строкой под кнопками.

## Чем это отличается от «Выключателя телевизора» на странице «Скрипты»

«Выключатель телевизора» — скрипт с ярлыками и командами, он делает то же самое, но снаружи программы и через
модуль PowerShell `DisplayConfig`, который нужно ставить из PowerShell Gallery. Страница «Экраны» ничего ставить не
требует: она обращается к Windows напрямую (Connecting and Configuring Displays, `QueryDisplayConfig` /
`SetDisplayConfig`). Скрипт остаётся для задач по расписанию и запуска из командной строки.

## Права

Прав администратора страница не требует: переключение экранов доступно обычному пользователю. Окно UAC не появляется.
