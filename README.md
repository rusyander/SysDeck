# Windows Process Cleaner

🇷🇺 Русский · [🇬🇧 English](README.en.md)

Обслуживание Windows в одном окне: **очистка диска**, **завершение забытых процессов**,
**разбор и освобождение оперативной памяти** (куда ушёл каждый гигабайт — схемой, в реальном
времени), **обновление установленных программ**, управление **автозапуском**, удаление программ
и чистка **Docker**.

Написана на **C# + WinForms**, собирается **встроенным в Windows компилятором
`csc.exe`** (.NET Framework 4.x). **Ничего устанавливать не нужно** — ни Node.js,
ни Rust, ни Visual Studio. Результат — один самодостаточный `.exe`, который можно просто
носить в папке.

---

## Для чего эта программа

Один инструмент вместо набора сторонних «оптимизаторов»: убрать зря висящие процессы,
освободить память, вычистить накопившийся мусор с диска и поставить вышедшие обновления —
без установки чего-либо в систему, с предпросмотром перед каждым удалением, с русским и
английским интерфейсом, работой из трея и по расписанию.

## Из чего состоит окно

Разделы — в боковой панели слева, как в Microsoft PC Manager.

| Раздел | Что делает |

| **Очистка диска** | анализ и удаление мусора по категориям, опционально правила winapp2 |
| **Диск** | карта папок с размерами, крупные файлы, пустые папки, дубликаты; удаление только в Корзину |
| **Браузеры** | закладки по папкам, сохранённые группы вкладок, список для чтения, открытые вкладки |

| **Настройки** | все пороги, списки и параметры |
| **История** | что и когда было очищено |

## Что программа умеет

- **Процессы** — находит забытые и заброшенные, завершает сначала мягко, потом принудительно.
- **Оперативная память** — показывает схемой, куда ушёл каждый гигабайт, и сбрасывает
  рабочие наборы, системный кэш и списки ожидания.
- **Dev Cleanup** — массово гасит Node/Python/Java/Vite/Webpack и освобождает занятые dev-порты.
- **Очистка диска** — dev-кэши, системный мусор, кэши браузеров и приложений, остатки
  обновлений Windows; по желанию подключается открытая база правил **winapp2**.
- **Диск** — дерево папок с размерами, крупные файлы, пустые папки, дубликаты по содержимому.
  Удаляет только в Корзину.
- **Docker** — показывает занятое место и удаляет неиспользуемое, сжимает vhdx.
- **Программы и обновления** — удаление штатным деинсталлятором, поиск вышедших версий
  и установка через **winget** и **Chocolatey**.
- **Браузеры** — закладки, группы вкладок, список для чтения и открытые вкладки; поиск
  повторов и проверка живости ссылок.
- **Автозапуск** — что стартует вместе с Windows, включение и отключение без удаления записей.
- **Windows: лишнее** — телеметрия, реклама, Copilot, лишние приложения и службы; с возвратом.
- **Автоматизация и оформление** — таймер очистки процессов, работа из трея, запуск с Windows,
  тёмная и светлая тема, русский и английский интерфейс.

## Чего программа НЕ делает (границы безопасности)

- **Не ломает Windows.** Системные процессы (SYSTEM/сервисы), компоненты из `C:\Windows`,
  критичные и защищённые процессы (оболочка, облака, драйверы, мессенджеры) в глобальном
  режиме под завершение не попадают; предохранители работают «в сторону защиты».
- **Не завершает активное по ошибке.** Кандидат в скане отбирается только при совпадении
  всех критериев сразу (мёртвый родитель + простой + нет окон/портов/детей), с
  подтверждением. Кнопки Dev Cleanup бьют по имени, не глядя на активность, но тоже сначала
  показывают список найденных процессов и спрашивают.
- **Не ищет дубликаты файлов по диску** и не удаляет ничего из ваших проектов, кода,
  System32 и корней дисков. Пакеты драйверов из `DriverStore` удаляются только через
  `pnputil` и только устаревшие. Чистятся только известные мусорные пути.
- **Не считает мусором сохранения и настройки.** Папки сохранений игр (`Saved Games`,
  `My Games`, `saves` / `SaveGames`, облачные сейвы Steam в `userdata`, сейвы Xbox) не
  становятся целью ни по встроенным правилам, ни по winapp2 — и не раскрываются при
  рекурсивном обходе, даже если правило указывает на папку выше них, — а корни профиля (Документы,
  Рабочий стол, AppData) не удаляются никогда. Любую папку любой категории можно исключить
  из очистки навсегда — через «Состав…».
- **Не чистит диск, не удаляет программы и не обновляет их по расписанию** — только
  вручную, с предпросмотром и подтверждением. По таймеру работает лишь очистка процессов.
- **Не правит реестр при обновлении программ.** Установку выполняет сам менеджер пакетов
  (winget / Chocolatey), приложение только показывает список и передаёт ему команду.
- **Docker: удаляет только неиспользуемое** (`prune`) — запущенные контейнеры и
  используемые образы не трогает. Kubernetes не включён.

## Безопасно ли это?

**Режим сканирования/автоочистки — да.** Кандидат отбирается только при совпадении
**всех** критериев сразу, поэтому активный процесс (с окном, слушающий порт, грузящий
CPU или с живым родителем) под удар не попадёт. В глобальном режиме дополнительно
защищены системные процессы и процессы других пользователей. Перед завершением
всегда запрашивается подтверждение.

**Dev Cleanup — нет**, это намеренно «кувалда»: кнопки бьют по имени всё подряд
(кроме белого списка), но перед ударом показывают список и ждут подтверждения.

## Установка коротко

| Требование | Пояснение |
|---|---|
| Windows 10 или 11 (x64) | Windows 8.1 тоже подойдёт |
| .NET Framework 4.x | **уже есть в Windows**, ставить не надо |
| Права администратора | **не нужны для запуска**, спрашиваются под конкретную операцию |

Ни Visual Studio, ни .NET SDK, ни Node.js не требуются: программа собирается компилятором
`csc.exe`, который уже лежит внутри Windows.

**Из исходников.** Скачайте репозиторий (ZIP — сначала правый клик → «Свойства» →
«Разблокировать») и запустите `run.bat`: он соберёт `WindowsProcessCleaner.exe` и откроет его.
Дальше можно запускать сам `.exe` — он самодостаточный и его можно носить в папке.

**Готовые сборки.** `build-installer.bat` собирает установщик `dist\WindowsProcessCleaner-Setup.exe`
и портативную версию в `dist\portable\`. Установка для текущего пользователя идёт без запроса
прав; портативная версия хранит настройки рядом с собой и не оставляет следов в системе.

Подробности, разбор ошибок сборки и удаление — [docs/install.md](docs/install.md).

## Права администратора

Окно запускается с обычными правами. Они поднимаются под конкретную операцию: программа
запускает саму себя вторым процессом, тот делает одну работу и завершается — одно окно UAC на
операцию, и в нём видно, ради чего оно. Всё внутри вашего профиля (кэши браузеров и приложений,
папки разработчика, Корзина, свои процессы) прав не требует и не спрашивает никогда; фоновая
работа не показывает UAC вовсе и пропускает недоступное, перечисляя пропущенное в журнале.
Подробнее — [docs/data-and-rights.md](docs/data-and-rights.md).
