# Скрипты

[🇬🇧 English](scripts.en.md) · [Руководство](README.md)

Страница «Скрипты» ставит в Windows набор скриптов обслуживания. Они лечат то, что Windows не лечит сама: зависшие
dev-серверы, залипший наблюдатель VS Code, молчащий после сна звук, фризы курсора на нескольких мониторах.
Скрипты встроены в SysDeck. Кнопка копирует их на диск и создаёт задачи Планировщика заданий. Ставить PowerShell-скрипты
вручную и запускать install-task.ps1 не нужно.

## Как пользоваться

Слева — список скриптов с состоянием и расписанием. Справа — выбранный скрипт: описание, папка, задачи Планировщика
с последним и следующим запуском, параметры и кнопки.

- **Установить отмеченные** ставит всё, что отмечено галочками, за один раз. При первом открытии страница сама
  отмечает то, что на этом компьютере стоит поставить или починить. Например, ремонт звука отмечается, только если
  нужное устройство вывода есть.
- **Установить / Сохранить / Установить заново** ставит скрипт или применяет изменённые параметры. Файлы копируются заново, задачи
  перерегистрируются, а задачи, ставшие ненужными при новых параметрах, удаляются. Выключенная задача остаётся
  выключенной: «Сохранить» меняет параметры, а не ваше решение.
- **Включить / Выключить** включает или выключает задачи скрипта, не удаляя их.
- **Запустить сейчас** запускает задачу вне расписания.
- **Журнал** открывает журнал скрипта в Блокноте. **Открыть папку** — папку, куда скрипт установлен.
- **Удалить** убирает задачи и файлы. Настройки, которые вы правили сами (например, `reap.config.json`), остаются.

Состояния в списке:

| Состояние | Что значит |
|---|---|
| работает / установлен | файлы на месте, задачи есть и включены |
| выключен | задачи есть, но выключены |
| файлы изменены | скрипт на диске отличается от встроенного; «Сохранить» вернёт встроенный |
| установлен не полностью | не хватает файла или задачи; справа написано, чего именно; «Сохранить» доложит |
| не установлен | ничего нет |

## Что входит

| Скрипт | Что делает | Когда работает | Параметры |
|---|---|---|---|
| Уборщик зависших процессов | убирает осиротевшие деревья node/cmd/conhost и dev-серверов; редактор, агенты и окна не трогает | каждые 4 ч | интервал, время отсчёта |
| Залипшие наблюдатели VS Code | завершает file-watcher, который крутится вхолостую и держит ядро (ошибка @parcel/watcher) | каждые 2 ч | интервал, время отсчёта |
| Приоритет агентов Claude | переводит каждое дерево claude.exe в пониженный приоритет и на верхнюю половину логических процессоров (при 24 потоках и больше), чтобы параллельные сессии не вешали игру | каждые 10 мин и при входе | интервал |
| Регистратор фризов | пишет в журнал каждое зависание системы дольше секунды: DPC, прерывания, диск, память, виновников | всё время после входа | — |
| Ловушка нехватки TCP-портов | на событие Tcpip 4231 записывает, какой процесс сколько портов держит | по событию | — |
| Ремонт молчащего звука | после загрузки и выхода из сна перезапускает цифровой выход (S/PDIF, HDMI); ярлык «Починить звук» | загрузка, выход из сна | устройство, пауза после сна, частота ремонта, перезапуск служб, сброс порта, переустановка драйвера, запись состояния, ярлык |
| Отключение MPO | параметр DWM `OverlayTestMode = 5` против фризов курсора на мониторах с разной частотой | параметр; по желанию — при каждом входе | переприменять при входе |
| Обслуживание Docker / WSL2 | ежедневно чистит старые остановленные контейнеры, висячие образы и кэш сборки; тома и работающие контейнеры не трогает | ежедневно в 04:00 | вкл/выкл, время |
| Лимиты памяти WSL2 | пишет в `%USERPROFILE%\.wslconfig` предел памяти, подкачку, возврат памяти Windows и уменьшение диска | при запуске WSL | память, подкачка, режим возврата, уменьшение диска |
| Хук Claude Code | в конце сессии Claude Code запускает уборщик процессов; нужны установленный уборщик и Node.js | конец сессии | — |
| Выключатель телевизора | отключает и включает HDMI-телевизор программно, чтобы выключенный ТВ не дёргал рабочий стол | вручную | имя ТВ, код оборудования |

У некоторых скриптов есть свои кнопки: «Что убрал бы сейчас» (пробный проход уборщика, ничего не завершает),
«Починить звук сейчас» и «Проверить устройство», «Отчёт Docker», «Перезапустить WSL», «Выключить ТВ», «Включить ТВ», «Состояние ТВ»,
«Установить модуль» (DisplayConfig для телевизора из PowerShell Gallery).

## Права и безопасность

- Большинство скриптов работает от вашего имени без повышения прав. Окно ставит их само, запрос UAC не появляется.
- Ремонт звука и отключение MPO требуют прав администратора: их задачи работают от имени SYSTEM, а MPO — это
  параметр в HKLM. Windows спросит разрешение один раз, после нажатия кнопки. Если отмечены оба, запрос тоже один.
- Скрипты, которые выполняет SYSTEM, ставятся в `%ProgramData%\SysDeck\toolkit`. Писать в эту папку могут только
  администраторы и SYSTEM: иначе любая программа пользователя могла бы подменить скрипт, который выполняется
  с наивысшими правами. Если путь заранее подменён точкой соединения (junction), установка отказывается.
- Старую установку ремонта звука в `%USERPROFILE%\.claude\tools\audio-fix` страница узнаёт и предлагает перенести.
  Задачи и ярлык после этого указывают на защищённую копию, старая папка остаётся на месте.
- Задачи запускаются через `wscript` и `run-hidden.vbs`: окно консоли не мелькает и не забирает фокус у игры.
- Перед первой правкой `.wslconfig` сохраняется копия `.wslconfig.sysdeck.bak`, перед правкой `settings.json`
  Claude Code — `settings.json.bak`. Меняются только ключи этой страницы, остальное содержимое файлов остаётся.
- Лимиты WSL действуют после перезапуска WSL. После сохранения страница предложит его; при перезапуске останавливаются
  все дистрибутивы и контейнеры Docker Desktop.

## Куда ставится

| Скрипт | Папка |
|---|---|
| уборщик, наблюдатели VS Code, приоритет агентов, регистратор фризов, ловушка портов, Docker | `%USERPROFILE%\.claude\tools\<имя>` |
| ремонт звука, MPO | `%ProgramData%\SysDeck\toolkit\<имя>` |
| хук Claude Code | `%USERPROFILE%\.claude\hooks` |
| выключатель телевизора | `%USERPROFILE%\Tools\tv-switch` |

Журналы: `%LOCALAPPDATA%\proc-reaper\reap.log`, `%LOCALAPPDATA%\vscode-watcher-reaper\watcher-reap.log`,
`%LOCALAPPDATA%\freeze-canary\stalls.log`, `%LOCALAPPDATA%\port-watch\4231.log`, `%ProgramData%\audio-fix\audio-fix.log`.
