# Торренты

Собственный клиент BitTorrent вкладки «Загрузки»: добавление торрентов и magnet-ссылок, раздача, обновление раздачи.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [Загрузки](downloads.md) · [🇬🇧 English](torrents.en.md)

Торренты качает тот же фоновый процесс, своим клиентом BitTorrent, без сторонних программ. Торрент стоит в общем
списке рядом с обычными загрузками.

Добавить торрент:
- **Торрент…** на панели — выбрать файл `.torrent`.
- `Ctrl+V` или перетаскивание в список: magnet-ссылки из текста и файлы `.torrent`. Одна и та же раздача, вставленная
  дважды с разными трекерами, добавляется один раз.
- Двойной щелчок по `.torrent` или magnet-ссылка в браузере, если программа назначена для них в настройках.

Диалог торрента:
- Список файлов с флажками и размерами, **Отметить все / Снять все**. У magnet-ссылки список придёт от пиров, поэтому
  сначала качается всё; ненужные файлы потом снимаются на вкладке «Файлы».
- **Папка** и свободное место на диске рядом с объёмом выбранных файлов. Если места не хватит, это видно сразу.
- **Имя папки раздачи** (у торрента из одного файла — имя файла).
- Если в папке уже лежат данные этой раздачи, флажок **проверить их, докачать недостающее и раздавать** берёт их
  вместо новой копии.
- **Начать** сразу или на паузе, **приоритет**, **качать куски по порядку**: видео можно смотреть, пока оно
  качается, но раздача от этого медленнее.

Без диалога, с настройками по умолчанию, торрентом становятся:
- файл `.torrent`, скачанный обычной загрузкой;
- файл `.torrent`, скачанный браузером, если программа не смогла забрать его у браузера;
- новый файл `.torrent` в **папке наблюдения**.

Тот же торрент второй раз не добавляется. Файл, который оказался страницей сайта с именем `.torrent`, остаётся
обычным файлом. Папка наблюдения просматривается раз в несколько секунд, пока работает фоновый процесс, и только
верхний уровень. Файл, который ещё пишется, ждёт следующего прохода. Торрент, убранный из списка, из папки не
возвращается, в том числе после перезапуска. Сам файл `.torrent` — накладная, а не груз: по умолчанию включено
**Убирать файл .torrent после добавления**, и сразу после добавления раздачи файл уходит в Корзину, а его загрузка
пропадает из списка (копию браузера удаляет сам браузер). Снимите галочку, если файлы `.torrent` нужно оставлять —
тогда загрузка остаётся в списке с отметкой в журнале. Содержимое торрента программа хранит у себя.

Когда включено **Спрашивать, куда скачивать**, вопрос задаётся и здесь — про саму раздачу, а не про файл `.torrent`:
до ответа торрент стоит и не качает ни байта. Отказ убирает такой торрент из списка: его туда никто не добавлял
руками, поэтому повторный щелчок на трекере начинает разговор заново.

В списке у торрента свои состояния: **проверка данных · N %**, **качается · пиры (сиды) · скорость отдачи**,
**раздаётся**. В меню записи вместо команд одной ссылки:
- **Проверить данные**, **Запросить пиров у трекеров**, **Качать по порядку**;
- **Копировать magnet-ссылку**;
- **Раздавать снова** у раздачи, остановленной по рейтингу или времени;
- **Новая версия раздачи** и, когда она найдена, **Обновить раздачу…** — см. ниже.

«Скачать заново», смена ссылки, зеркала и перенос торренту недоступны.

## Новая версия раздачи
Раздачу на трекере перезаливают: добавили серии, заменили файл. Старая перестаёт раздаваться, у новой другой
info-hash. Программа находит новую версию и переводит на неё ту же запись: скачанное остаётся на месте,
докачивается только изменённое.

Ссылку на тему программа берёт из самого `.torrent` (поле комментария или сайта издателя) и показывает её в карточке
строкой **Тема раздачи**. Сама проверяет только rutracker, через его открытый API `api.rutracker.cc`, без входа на
сайт:
- раз в 6 часов, пока включено **Проверять новые версии раздач rutracker раз в 6 часов**;
- сразу, если трекер ответил «Torrent not registered», но не чаще раза в час на раздачу.

Для других трекеров (nnmclub, kinozal, rutor и т. п.) новую версию берут файлом со страницы темы.

Когда новая версия найдена:
- приходит уведомление, в списке к состоянию добавляется **есть новая версия**, в карточке — строка **Новая версия**;
- программа запрашивает у пиров метаданные новой версии через трекеры прежней, с тем же ключом доступа. В папку
  загрузки при этом ничего не пишется. Если пиров нет, повтор через час;
- сама раздача не меняется, пока вы не нажмёте **Обновить**.

В меню записи, подменю **Новая версия раздачи**:
- **Проверить на rutracker сейчас** — только у раздач с темой rutracker;
- **Взять из файла .torrent…** — любой трекер, тема не сверяется. Файл той же версии программа отклонит, а что
  станет с файлами, видно в окне до обновления;
- **Открыть страницу темы** — в браузере по умолчанию.

Если открыть `.torrent` той же темы, что у раздачи в списке, но с другим info-hash, программа сначала спросит:
**Да** — обновить эту раздачу, **Нет** — добавить отдельной загрузкой. Такой файл из папки наблюдения или скачанный
обычной загрузкой становится новой версией без вопроса, но и он ничего не заменяет до кнопки.

**Обновить раздачу…** открывает окно «Новая версия раздачи». В нём info-hash, итог по файлам (остаются, переносятся,
изменены, новые, в Корзину) и список «что будет» с каждым файлом. Кнопки:
- **Обновить** — останавливает раздачу, отправляет в Корзину файлы, которых в новой версии нет, переносит
  переименованные и проверяет данные хешем новой версии. Докачиваются только изменённые и новые файлы, снятые
  флажки «не качать» сохраняются, имя папки не меняется;
- **Не обновлять** — эта версия больше не предлагается, следующая будет;
- **Закрыть** — ничего не меняет;
- **Открыть страницу темы** и **Из файла .torrent…** — если нужна другая версия.

Если метаданных ещё нет, окно говорит об этом, и **Обновить** недоступна. Обновить нельзя и в таких случаях
(причину окно пишет над кнопками):
- это та же версия;
- раздача стала папкой или, наоборот, одним файлом — такую добавляют отдельно;
- новая версия только BitTorrent v2;
- на месте новых файлов лежат чужие файлы.

Пока идёт обновление, запись нельзя запустить, проверить или удалить. Если процесс завершился на полпути, при
следующем запуске он доводит обновление до конца.
