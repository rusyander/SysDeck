# Установка

Требования, сборка из исходников, готовый установщик и портативная версия, удаление.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [🇬🇧 English](install.en.md)

## Что нужно

| Требование | Пояснение |
|---|---|
| Windows 10 или 11 (x64) | Windows 8.1 тоже подойдёт |
| .NET Framework 4.x | **уже есть в Windows**, ставить не надо |
| Права администратора | **не нужны для запуска.** Спрашиваются под конкретную операцию — очистка системных папок, Standby Memory, восстановление системных файлов |

Ни Visual Studio, ни .NET SDK, ни Node.js, ни какие-либо пакеты **не требуются** —
программа собирается компилятором `csc.exe`, который уже лежит внутри Windows.

Отдельно (по желанию, только для соответствующих вкладок):

- **winget** — для вкладки «Обновления». В Windows 11 и свежих Windows 10 он есть
  из коробки; если нет — установите «Установщик приложений» (App Installer) из
  Microsoft Store.
- **Chocolatey** — необязательный второй источник обновлений. Если он не установлен,
  вкладка просто работает через один winget.
- **Docker Desktop** — для вкладки Docker (нужен запущенный демон).

## Шаги

1. **Получите файлы.** Либо `git clone` репозитория, либо скачайте ZIP и распакуйте
   его в любую папку, например `C:\Tools\cleaner`.

2. **Если скачивали ZIP — снимите блокировку.** Windows помечает файлы из интернета, и
   сборка может отказаться работать. Правый клик по ZIP → **Свойства** → внизу галочка
   **«Разблокировать»** → OK, и только потом распаковывайте. Уже распаковали — выполните
   в PowerShell в папке проекта:

   ```powershell
   Get-ChildItem -Recurse | Unblock-File
   ```

3. **Запустите `run.bat`** двойным кликом. При первом запуске он соберёт
   `WindowsProcessCleaner.exe` и сразу откроет его. Дальше можно запускать сам `.exe`.

   Только сборка, без запуска:

   ```
   build.bat
   ```

4. **Запрос UAC при запуске не появится.** Программа работает с обычными правами
   пользователя. Windows спросит разрешение только тогда, когда вы запустите операцию,
   которой права действительно нужны, — и в вопросе будет видно, ради чего именно.

Всё. Устанавливать в систему ничего не нужно: `WindowsProcessCleaner.exe` —
самодостаточный файл, его можно просто носить с собой в папке.

## Готовые сборки: с установщиком и без

Команда `build-installer.bat` собирает обе сразу и кладёт их рядом, в папку `dist`:

| Что получается | Где |
|---|---|
| Установщик | `dist\WindowsProcessCleaner-Setup.exe` |
| Портативная версия | `dist\portable\` |

**Установка.** Запустите `WindowsProcessCleaner-Setup.exe`. По умолчанию программа
ставится только для вас, в `%LOCALAPPDATA%\Programs\WindowsProcessCleaner`, и никакого
запроса прав администратора при этом не появляется. Флажок «для всех пользователей»
переносит установку в `Program Files` — тогда Windows один раз спросит разрешение.
Можно выбрать другую папку и снять галочку с ярлыка на рабочем столе. Установщик создаёт
ярлык в меню «Пуск», запись в списке установленных программ и `uninstall.exe` рядом с
программой. Повторная установка поверх старой просто обновляет файлы: ярлыки не
задваиваются, настройки и история остаются на месте. Если программа в этот момент
запущена, установщик покажет это и предложит её закрыть — сам он ничего не завершает
без вашего согласия.

**Удаление.** «Параметры → Приложения → Windows Process Cleaner → Удалить» или
`uninstall.exe` из папки программы. Будут удалены файлы, ярлыки, задача автозапуска и
запись в списке программ. Флажок «удалить также настройки и историю» по умолчанию снят:
запомненный выбор, настройки и история лежат в `%APPDATA%\WindowsProcessCleaner` и
сохраняются до полного удаления программы — снятый флажок означает, что после новой
установки всё вернётся как было.

**Портативная версия.** Папка `portable` — та же программа без установки: распакуйте
куда угодно, хоть на флешку. Настройки, история и журналы пишутся рядом с exe, в подпапку
`Data`; за это отвечает файл `portable.marker` — держите его рядом с программой. Чтобы
удалить портативную версию, достаточно стереть папку: в системе не остаётся ничего.

## Если что-то не пошло

**«Windows защитила ваш компьютер» (SmartScreen).** Файл собран у вас локально и не
подписан сертификатом, поэтому Windows его не знает. Нажмите **«Подробнее»** →
**«Выполнить в любом случае»**.

**Антивирус ругается на свежесобранный `.exe`.** Это ложное срабатывание на
неподписанный файл. Добавьте папку проекта в исключения или соберите заново.

**`[ERROR] csc.exe of .NET Framework 4.x not found`.** В системе нет .NET Framework 4.x
(бывает на сильно урезанных сборках Windows). Установите .NET Framework 4.8 с сайта
Microsoft и повторите.

**`[ERROR] Build failed`.** Чаще всего программа уже запущена и держит свой `.exe`.
Закройте её (в том числе из трея — правый клик по иконке → «Выход») и соберите снова.

**Окно не появилось после запуска.** Вероятно, приложение уже работает: оно
однооконное и просто разворачивает уже открытое окно. Посмотрите в трей у часов.

**Не собирается из папки с очень длинным путём.** Перенесите проект ближе к корню
диска, например в `C:\Tools\cleaner`.

## Как удалить

1. В настройках снимите галочку **«Запускать вместе с Windows»** — задача
   `WindowsProcessCleaner` в Планировщике задач удалится.
2. Закройте программу (трей → «Выход»).
3. Удалите папку проекта и папку настроек `%APPDATA%\WindowsProcessCleaner\`.

Ничего другого в системе программа не оставляет: в реестр она себя не прописывает
и служб не создаёт.
