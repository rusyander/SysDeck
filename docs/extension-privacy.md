# Конфиденциальность: расширение «Windows Process Cleaner — загрузки»

Какие данные читает браузерное расширение для Chrome, Edge, Яндекс Браузера и Firefox, куда их передаёт и
чего не делает никогда.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [🇬🇧 English](extension-privacy.en.md)

## Коротко

Ничего не покидает ваш компьютер. Расширение общается только с программой Windows Process Cleaner,
установленной на этом же компьютере, через механизм браузера native messaging (хост `org.wpc.downloads`).
У расширения нет своего сервера, аналитики, рекламы и телеметрии, оно не загружает код из сети и само не
делает сетевых запросов — сеть использует только браузер, когда качает файл.

## Что читается и когда

| Данные | Когда | Кому передаётся |
|---|---|---|
| Адрес загрузки, итоговый адрес после перенаправлений, адрес страницы-источника (referrer), имя файла, тип, размер, признак приватного окна, строка User-Agent браузера | когда вы сами начинаете загрузку в браузере | программе на этом компьютере — чтобы она решила, качать ли файл самой |
| Cookie сайта | только для адреса этой загрузки или ссылок, которые вы выбрали в контекстном меню, и только в этот момент | программе на этом компьютере — чтобы сайт отдал файл так же, как браузеру. Расширение cookie не хранит |
| Адреса ссылок на странице | только после вашего выбора «Скачать все ссылки…» или «Скачать выделенные ссылки…», только во вкладке, где вы нажали | программе на этом компьютере |
| Имя сайта открытой вкладки | когда вы открываете окно расширения — чтобы показать переключатель «Не перехватывать на этом сайте» | программе — только имя сайта и только когда вы нажимаете этот переключатель |

## Что не читается никогда

История браузера, содержимое страниц (кроме адресов ссылок по вашей команде из меню), адреса других вкладок,
закладки, пароли, данные форм.

## Что хранится

Расширение держит в сессионном хранилище браузера только список загрузок, для которых программа попросила
сообщить о завершении; он очищается при закрытии браузера. Правила перехвата (включено ли, исключённые сайты и
расширения файлов) хранит сама программа на компьютере. Данные никому не продаются и третьим лицам не
передаются.

## Зачем нужны разрешения

| Разрешение | Зачем |
|---|---|
| `downloads` | увидеть начатую загрузку, отменить её в браузере, если файл взяла программа, или вернуть загрузку браузеру |
| `nativeMessaging` | связь с программой на этом компьютере |
| `cookies` и доступ ко всем сайтам | прочитать cookie для адреса загрузки — файл может быть на любом сайте |
| `contextMenus` (в Firefox `menus`) | пункты «Скачать…» в контекстном меню |
| `activeTab`, `scripting` | собрать адреса ссылок во вкладке — только по вашему клику в меню |
| `storage` | список загрузок, за которыми нужно проследить до завершения |
