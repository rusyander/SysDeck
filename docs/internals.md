# Технические детали

Используемый WinAPI, разбор вывода менеджеров пакетов, ключи командной строки, состав репозитория.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [🇬🇧 English](internals.en.md)

- **WinAPI:** `CreateToolhelp32Snapshot`, `EnumWindows`, `GetExtendedTcpTable`,
  `OpenProcessToken`/`GetTokenInformation` (владелец процесса),
  `SendMessageTimeout(WM_CLOSE)`, `TerminateProcess` (через `Process.Kill`),
  `NtSetSystemInformation` (Standby Memory), `GlobalMemoryStatusEx`,
  `DwmSetWindowAttribute` (тёмный заголовок), `FindFirstFileExW` (обход диска с длинными
  путями `\\?\`), `SHFileOperationW` (удаление в Корзину), `SetWindowTheme` (тёмные
  полосы прокрутки).
- **Обновления программ:** вызываются `winget.exe` и `choco.exe`. Вывод `winget upgrade`
  не имеет машинно-читаемого формата (только таблица), поэтому таблица разбирается по
  позициям начала колонок из строки заголовка и по их **порядку**, а не по названиям —
  так разбор работает и на локализованном winget. Позиции считаются в ячейках терминала,
  а не в символах: иероглифы, хангыль и полноширинные символы занимают две ячейки, и строка
  с таким именем короче заголовка. Вторая таблица winget («требуется явное указание для
  обновления») разбирается по собственному заголовку.
- **Деинсталляция:** строка `UninstallString` из реестра делится на exe и аргументы самим
  приложением и запускается через `ShellExecute`, а не через `cmd /c`: cmd снимает кавычки
  с пути, где есть `&`, не запускает путь с пробелами без кавычек (Android Studio, Steam,
  InstallShield) и ломается на командах с четырьмя кавычками (NVIDIA через `RunDll32`,
  Docker Desktop). `MsiExec /I{GUID}` — это диалог восстановления, поэтому для MSI-пакетов
  вызывается `/X{GUID}` — то же, что делает «Программы и компоненты».
- **Single-instance** — именованный `Mutex` (`Local\WindowsProcessCleaner.singleinstance`).
  Локальный TCP-порт **49876** используется только для того, чтобы попросить уже
  запущенный экземпляр показать окно; если порт занят, приложение всё равно запустится
  нормально.
- **Мониторинг** процессов идёт в фоновом потоке (не в UI), период настраивается
  (5..300 с, по умолчанию 15). Данные о процессах берутся напрямую через
  `OpenProcess` + `GetProcessTimes`/`GetProcessMemoryInfo`, а не через
  `Process.GetProcessById` — последний делает полный снимок системы на каждый вызов, и на
  600+ процессах один проход занимал десятки секунд.
- Поэтому «5 минут простоя» отсчитываются с момента, как приложение начало наблюдать за
  процессом, а не с его запуска.
- **Ключи командной строки:** `/tray` — стартовать свёрнутым, `/auto` — тихая очистка
  диска без окна для собственной задачи планировщика (рекомендованные категории с учётом
  галочек, снятых или поставленных в окне; код возврата виден планировщику), `/analyze` —
  посчитать мусор на диске без удаления
  (строка `TOTAL` — без двойного счёта вложенных целей, `sum=` — простая сумма категорий),
  `/disk [путь]` — открыть вкладку «Диск» и сразу просканировать путь; если окно уже открыто,
  путь передаётся ему, второе окно не появляется.
- **Ключи «Размеров папок»** (проверяются раньше мьютекса окна, окну не мешают): `--foldersize` —
  фоновый режим (трей, панель, числа в Проводнике; повторный запуск лишь показывает панель),
  `--foldersize-exit` — остановить его, `--foldersize-measure <папка> [--hidden]` — тот же подсчёт
  в консоль, с временем по каждой папке (сверять с другим инструментом), `--foldersize-probe <hwnd>`
  — что читается из окна Проводника через UI Automation (колонка «Размер», строки, ячейки),
  `--foldersize-autostart on|off` — автозапуск для сценария или установщика. Окно и фоновый
  процесс связаны именованными событиями с доступом для текущего пользователя: фоновый процесс
  с правами администратора слышит окно без прав, а оконные сообщения UIPI бы отбросил.
- **Ключи «Захвата»** (тоже раньше мьютекса окна): `--capture` — фоновый процесс снимков (горячие
  клавиши, выделение области, уведомления; второй запуск сразу завершается), `--capture-exit` —
  остановить его (код 1, если он не запущен), `--capture-shot region|screen|window` — попросить
  работающий процесс о снимке, например из ярлыка или сценария (код 1 — процесс не запущен, 2 —
  неизвестный вид). Связь та же: именованные события с доступом для текущего пользователя.
  Горячие клавиши — `RegisterHotKey`, без глобального перехвата клавиатуры; снимки — `BitBlt` с
  рабочего стола в физических пикселях (поток в режиме Per-Monitor DPI v2); уведомление
  исключено из захвата через `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`.
- **Масштаб экрана (DPI):** окно масштабируется под 125/150 % (`AutoScaleMode.Dpi`),
  панели кнопок переносят кнопки на следующую строку, колонки настроек считаются от ширины
  подписей, а минимальный размер окна не превышает рабочую область экрана.
- **Загрузки:** отдельный процесс `--downloads` качает файл до 4 сегментами
  (до 16, не больше 8 соединений на сервер), держит до 3 загрузок сразу и до 2 с одного сайта.
  Докачка после закрытия или падения идёт с байтов, уже сброшенных на диск, и с `If-Range`: если файл
  на сервере сменился, загрузка останавливается, а не склеивает две версии. Редиректы — не больше 10,
  переход с https на http только с согласия; cookies уходят лишь тому хосту, для которого выданы.
  Готовый файл сверяется по SHA-256 (и с ожидаемым хешем, если он указан), переименовывается из
  `.wpcpart` и получает метку «из интернета» через `IAttachmentExecute`. Условия запуска: расписание,
  отложенный старт, лимитная сеть, батарея и простой ПК (5 минут без ввода, процессор ниже 30 %,
  нет полноэкранного приложения). Удаление файла загрузки — только в Корзину.
  Вкладка «Загрузки» — клиент канала: опрашивает процесс раз в 700 мс (без него читает хранилище раз в
  3 секунды и ничего в нём не меняет), команды отправляет в фоновом потоке и поднимает процесс, только когда
  команда меняет очередь. Имена канала, мьютекса, события остановки и значения автозапуска получают суффикс из
  SHA-256 пути папки данных, если она не стандартная: копия со своей папкой не управляет чужой очередью.
  Подпись перед запуском программы — `WinVerifyTrust` без интерфейса и без проверки отзыва через сеть.
- **Падения:** необработанное исключение (в UI-потоке и в фоновых) пишется в `crash.log`
  в папке данных, после чего показывается одно сообщение вместо тихого закрытия.

## Файлы проекта

| Файл | Назначение |
|------|-----------|
| `src\*.cs` | код приложения, по файлу на область: `Program.cs` (вход, ключи), `Engine*.cs` (логика: процессы, очистка, диск, драйверы, winapp2, обновления, программы, автозапуск, Docker, проверка состояния, инструменты), `MainForm*.cs` (окно, по разделу на файл; «Загрузки» — `MainForm.Downloads*.cs`), `Native.cs` (WinAPI), `Theme.cs`, `Json.cs`, `Browser*.cs`, `FastListView.cs`, `FolderSize.*.cs` (фоновый режим «Размеры папок»: подсчёт, чтение $MFT, Проводник через UI Automation, наложение, панель, трей), `Downloads.*.cs` (движок загрузок в отдельном процессе: сегменты, докачка, очередь, ограничения скорости, условия запуска, метка «из интернета», именованный канал; `Downloads.View.cs` — что показывает вкладка, `Downloads.Verify.cs` — подпись, `Downloads.Bridge.cs` — хост native messaging для расширения браузера: проверка ссылки одним запросом, передача загрузки фоновому процессу, `Downloads.Browsers.cs` — ключи реестра, манифесты, распаковка расширения) |
| `extension\` | браузерное расширение: `src\` (общий код, окно, `_locales`), `manifest.chromium.json` и `manifest.firefox.json`, `test\` (тесты на Node: `node --test test/*.test.js`). Встраивается в exe ресурсами при сборке, без `test\` |
| `tools\pack-extension.ps1` | собрать распакованные папки и zip для каталогов расширений в `dist\` |
| `app.manifest` | манифест (asInvoker, DPI, длинные пути) |
| `installer\*.cs` | код установщика и деинсталлятора (отдельная программа, свой манифест) |
| `build-installer.bat` | собрать обе готовые сборки в `dist\` |
| `tests\*.cs`, `tests\run-tests.bat` | набор тестов (запуск без прав администратора); как запускать и что покрыто — [tests.md](tests.md) |
| `icon.ico` | иконка приложения (встраивается в exe) |
| `build.bat` | сборка всех `src\*.cs` через встроенный csc.exe |
| `run.bat` | собрать при необходимости и запустить |
| `README.md` / `README.en.md` | обзор проекта (рус / англ) |
| `docs\*.md` / `docs\*.en.md` | подробное руководство по разделам (рус / англ) |
