# Захват: скриншоты и видео по горячим клавишам

Вкладка «Захват»: снимок или видео со звуком области, экрана или окна по горячей клавише, уведомление с миниатюрой, раскладка файлов по папкам программ.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [🇬🇧 English](capture.en.md)

> Работают скриншоты, редактор снимков, запись видео со звуком и галерея снимков и записей.

## Фоновый процесс
Снимки делает отдельный процесс того же exe (`SysDeck.exe --capture`), поэтому горячие клавиши
работают и при закрытом окне программы. Процесс идёт **без прав администратора**, даже если окно запущено с ними:
так он видит обычные окна и не требует UAC. Снимки никуда не отправляются.

- Процесс **стартует вместе с окном программы** — горячие клавиши работают сразу, нажимать ничего не нужно.
- **Запустить / Остановить** — кнопки вверху вкладки; строка над ними показывает, работает ли процесс.
  «Остановить» запоминается: пока не нажата «Запустить», процесс не поднимается ни с окном, ни из меню.
- **Запускать вместе с Windows** — значение `SysDeck.Capture` в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`: процесс стартует при входе в систему с обычными правами.
- **Снимок области** и **Видео области** — проверить, что всё работает, не нажимая сочетание.
- В меню значка в трее есть подменю «Захват»: снимок области, экрана или окна, видео области или экрана,
  остановка записи, папки снимков и видео, настройки. Если
  фоновый процесс не запущен, меню запускает его и выполняет команду; если он остановлен кнопкой, меню
  открывает вкладку, а не запускает его само: иначе процесс молча занял бы горячие клавиши.

## Горячие клавиши
По умолчанию — те же клавиши, что у VK Play GameCenter, чтобы не переучиваться:

| Действие | Сочетание |
|---|---|
| Скриншот области | `F3` |
| Скриншот экрана | `F4` |
| Видео области: начать / остановить | `F7` |
| Показатели ПК поверх всего: показать / скрыть | `Alt+R` |
| Оверлей: сбросить мин. / сред. / макс. | `Ctrl+Alt+R` |
| Оверлей: следующий набор строк | `Ctrl+Alt+N` |
| Запись лагов: начать / остановить | `Ctrl+Alt+L` |
| Активная игра: без рамки на весь экран / вернуть | `Ctrl+Alt+B` |
| Скриншот активного окна, видео экрана, пауза записи, галерея | не назначены |

- Щёлкните поле и нажмите сочетание. `Backspace` убирает сочетание, `Esc` оставляет прежнее. Пока поле в
  фокусе, фоновый процесс отпускает свои клавиши, чтобы нажатие дошло до поля.
- **Занятое сочетание.** Windows отдаёт клавишу только одной программе. Если её держит другая, рядом с полем
  появится предупреждение, по возможности с именем владельца (Ножницы Windows, Xbox Game Bar, NVIDIA App,
  VK Play GameCenter, панель «Размеров папок»). Фоновый процесс повторяет попытку каждые 15 секунд: когда та
  программа закроется или освободит клавишу, сочетание заработает без перезапуска.
- **Забирать сочетание, занятое другой программой** (включено по умолчанию). Так `Alt+R` достаётся оверлею этой
  программы, даже когда NVIDIA App держит его для своего счётчика (у NVIDIA занят и `Ctrl+Alt+R`): пока работает
  фоновый процесс захвата, нажатие перехватывается раньше, чем Windows отдаст его владельцу, и до NVIDIA не доходит.
  Рядом с полем тогда написано «✓ работает · забрано у …». Сочетания с `Win` не забираются. Снимите галочку —
  клавиша вернётся прежнему владельцу.
- **Обновление программы.** Фоновый процесс замечает, что `SysDeck.exe` заменили (пересборка,
  установщик), и перезапускается сам, как только не занят: нет записи, выделения, открытого редактора или
  галереи. Новые сочетания и команды начинают работать без ручного «Остановить → Запустить».
- **Перенести из VK Play GameCenter** — прочитать `%LOCALAPPDATA%\GameCenter\GameCenter.ini`: сочетания
  снимков и видео и папки сохранения (папка берётся, только если она существует). При первом запуске модуля
  перенос выполняется сам, если файл найден. Пока GameCenter запущен, он держит свои клавиши — вкладка об этом
  предупреждает.
- **Сочетания по умолчанию** — вернуть таблицу выше.
- **Не отдавать PrtScn «Ножницам» Windows** — нужна, только если вы назначили сочетание с `PrtScn`. Меняет
  параметр Windows «Использовать кнопку PrtScn для открытия ножниц»
  (`HKCU\Control Panel\Keyboard\PrintScreenKeyForSnippingEnabled`); при снятии галочки прежнее значение
  возвращается.

## Выделение области
Экран замирает и темнеет, выделенная часть показывается в исходной яркости. Выделение работает на всех
мониторах сразу и в физических пикселях при любом масштабе экрана.

| Что сделать | Как |
|---|---|
| Выделить область | тянуть мышью; подпись показывает размер в пикселях |
| Взять окно целиком | щелчок по окну: под курсором подсвечивается окно без невидимой рамки Windows |
| Взять весь монитор | двойной щелчок |
| Прошлая область | `L` |
| Изменить выделение | тянуть за ручки по углам и сторонам |
| Сдвинуть выделение | тянуть внутри рамки; при выделении — зажать `Space` |
| Пропорции | `Shift` при выделении; `A` переключает 1:1 → 16:9 → 4:3 → 21:9 |
| Точная подгонка | стрелки двигают на 1 px (`Shift` — на 10), `Ctrl` + стрелки меняют размер |
| Цвет пикселя | лупа у курсора показывает цвет и координаты; `C` копирует цвет как `#RRGGBB` |
| Готово | `Enter` — действие из настройки «После снимка», `Ctrl+C` — в буфер, `Ctrl+S` — в файл, `E` — в редактор, или кнопки панели под выделением |
| Отмена | `Esc`; правая кнопка мыши сначала снимает выделение, второй раз закрывает |

Панель под выделением всегда в две строки: сверху инструменты пометок и цвета, снизу отмена правок, копирование,
редактор, запись и две подписанные кнопки — **«Сохранить»** (синяя, то же, что `Enter`) и **«Отмена»** (то же, что
`Esc`; под курсором краснеет). У видео вместо «Сохранить» — **«Начать запись»**. Панель целиком остаётся на мониторе,
даже если выделение вровень с краем экрана или занимает его весь: тогда она встаёт внутрь выделения. Если панель с
подписями всё равно шире монитора, обе кнопки сжимаются до значков; подсказка с клавишей есть у каждой кнопки.

Оверлей появляется примерно через 0,15 с после нажатия клавиши даже на трёх мониторах суммарно в 23 Мп: кадр
снимается прямо в память, а на экран выводится одной операцией GDI без промежуточной копии.

Переключение в другое окно (`Alt+Tab`, всплывшее окно) отменяет выделение, как у Ножниц Windows.

## Пометки прямо на выделении
Когда область выделена, на панели под ней кроме действий есть инструменты: рамка, овал, стрелка, линия, карандаш,
маркер, текст, номер шага, пять цветов и «Другой цвет…». Выбор инструмента включает рисование прямо поверх
выделения, без отдельного окна. Сам снимок не меняется: пометки ложатся поверх него.

- **Несколько пометок разными цветами.** Цвет действует на следующую фигуру: красная рамка остаётся красной, когда
  после неё выбран зелёный. Цвет меняется только у текста, который сейчас набирается.
- **Правка нарисованного.** Ручки фигуры под курсором меняют её размер при любом инструменте. Щелчок по фигуре без
  протягивания выделяет её, `Delete` или кнопка «Удалить» убирает. Отмена и повтор — `Ctrl+Z` / `Ctrl+Y` или
  кнопки на панели.
- **Область меняется и после рисования.** Ручки выделения расширяют или сужают снимок, пометки остаются на своих
  местах экрана. Ушедшие за край не пропадают и вернутся, если область снова расширить.
- **Готово.** `Enter` или «Сохранить» — как у обычного снимка, по настройке «После снимка»; `Ctrl+C` — в буфер
  вместе с пометками; `E` — в редактор снимка с нарисованным и историей отмены (там размытие, обрезка, толщина).
  Выбранные цвет и инструмент запоминаются вместе с настройками редактора.
- **Отмена.** `Esc` сначала снимает выделение с фигуры, второе нажатие закрывает оверлей без сохранения. Правая
  кнопка мыши при начатых пометках ничего не сбрасывает. Кнопки записи видео с пометками нет: в видео попал бы
  экран, а не пометки.
- **Весь монитор** тоже размечается: двойной щелчок берёт монитор, панель ложится внутрь выделения. `F4` снимает
  экран сразу, без оверлея.

## Сохранение
- **Папка** — по умолчанию `Изображения\Screenshots`. «Выбрать папку…», «Открыть папку», «По умолчанию».
- **Раскладывать по папкам программ** — снимок попадает в подпапку по имени программы, окно которой было под
  выделением: `Chrome`, `Visual Studio Code`, название игры. Снимок рабочего стола или панели задач попадает в
  `Рабочий стол` (при английском интерфейсе — `Desktop`).
- **Имя файла** — шаблон: `{app}` — программа, всё остальное в фигурных скобках — формат даты и времени
  (`{yyyy-MM-dd_HH-mm-ss}`, `{dd.MM.yy}`, `{HHmm}`). По умолчанию `{app}_{yyyy-MM-dd_HH-mm-ss}`, под полем
  показан пример. Недопустимые в имени символы заменяются; если файл уже есть, добавляется `_2`, `_3`…
- **Формат** — PNG (без потерь) или JPG с выбором качества.
- **После снимка** — сохранить и скопировать, только сохранить, только скопировать в буфер или открыть
  [редактор](#редактор-снимка), ничего не сохраняя.

## Снимок
- **«Скриншот экрана» снимает** монитор под курсором, все мониторы или активное окно.
- **Задержка** — нет, 3, 5 или 10 секунд: успеть открыть меню или подсказку.
- **Показывать курсор мыши на снимке** и **звук затвора** — по желанию, по умолчанию выключены.

## Видео
Запись идёт в MP4 (H.264, HEVC или AV1) на видеокарте, если её кодировщик прошёл пробное кодирование, иначе
программным кодировщиком Windows — тогда уведомление об этом скажет. Кодировщик «Авто» при видеокарте NVIDIA
сначала пробует её NVENC, даже если монитор подключён к встроенной видеокарте; без NVIDIA — кодировщик карты монитора.

- **Как начать.** `F7` открывает то же выделение, что у снимка: протяните область, щёлкните окно или дважды щёлкните
  монитор, затем `Enter` или кнопка «Начать запись». «Видео экрана» (сочетание не назначено) сразу пишет монитор
  под курсором. Во время выделения `R` превращает выделенную для снимка область в запись.
- **Как остановить.** Повторное нажатие той же клавиши (любой из двух клавиш записи), кнопка «Стоп» на панели
  записи, щелчок по красному значку в трее или «Остановить запись» в меню. Пауза — кнопка на панели, пункт меню
  красного значка или своё сочетание; время на паузе в файл не попадает, звук и картинка остаются синхронными.
- **Панель записи** с таймером и размером файла стоит под областью (нет места — над ней), тонкая рамка обводит
  область. Ни панель, ни рамка, ни уведомления в видео не попадают. На системах старше Windows 10 2004, где окно
  нельзя исключить из захвата, панель, которая легла бы на записываемую область, не показывается — остаётся значок
  в трее.
- **Запись окна** идёт за самим окном: его можно двигать и перекрывать, размер видео остаётся размером окна в
  момент старта. Закрыли или свернули окно — запись сохраняется и останавливается.
- **Кодек, кодировщик, качество, кадров в секунду** (30 или 60), **размер** (как у источника, не больше 1080p или
  720p — только уменьшение), **отсчёт** перед стартом (3 или 5 секунд), **не дольше** (10–120 минут).
  «Проверить кодировщики» показывает, какие из них на этом компьютере действительно работают.
- **Если запись оборвалась** (сбой, выключение питания): H.264 и AV1 пишутся фрагментами, и при следующем запуске
  фонового процесса файл восстанавливается — уведомление «восстановлено после обрыва записи»; прежний файл уходит в
  Корзину. HEVC пишется обычным MP4, такой файл после обрыва не восстановить — вкладка предупреждает об этом.
- Запись сама останавливается и сохраняет файл, когда на диске остаётся меньше 1 ГБ.
- Игра в эксклюзивном полноэкранном режиме и защищённое видео дают чёрный кадр — уведомление посоветует режим
  «Оконный без рамки».
- **Показывать курсор мыши в видео** — по умолчанию включено.

## Звук в видео
- **Звук системы** — всё, что слышно в колонках. **При записи окна — только его звук**: звук процесса окна вместе
  с дочерними процессами (Windows 10 2004 и новее; на старых системах пишется весь звук, уведомление об этом
  скажет).
- **Микрофон** — устройство (по умолчанию — выбранное в Windows), громкость от 50 до 300 %, **моно** (голос
  одинаково в обоих каналах). Отключённая гарнитура остаётся в списке как «не подключено», запись тогда берёт
  микрофон по умолчанию. «Проверить микрофон» 15 секунд показывает уровень сигнала.
- Если доступ к микрофону запрещён в «Параметры → Конфиденциальность → Микрофон», вкладка предупреждает, а видео
  пишется без микрофона. Занятое или пропавшее устройство тоже не мешает записи: в уведомлении будет причина.
- **Отдельные дорожки для монтажа**: дорожка 1 — общий звук (его играет любой плеер), 2 — система, 3 — микрофон.

## Уведомление
После снимка в правом нижнем углу того монитора, где он сделан, появляется карточка с миниатюрой.

- У видео заголовок «Видео сохранено · длительность · размер», а вместо имени файла — предупреждения записи, если
  они были. Кнопка копирования кладёт в буфер сам файл, редактора у видео нет.
- Щелчок по карточке открывает файл. Главная кнопка — **«Галерея»**: открывает окно галереи снимков и записей, в
  котором этот файл уже выделен. Остальные кнопки:
  **редактировать**, **копировать** в буфер, **показать в папке**, **удалить в Корзину**, **закрыть**. Удаление
  выполняется, когда карточка закроется, а до тех пор его можно отменить кнопкой «Отменить».
- Пока курсор над карточкой, она не исчезает. Одновременно показывается до трёх карточек на монитор.
- Карточка не попадает в следующие снимки и в запись экрана (на Windows 10 2004 и новее; на более старых
  системах она прячется на время снимка).
- **Держать** — от 3 до 15 секунд. Ошибки показываются всегда и держатся не меньше 8 секунд, даже если
  уведомления выключены.
- **Настройки ранних сборок.** В `capture\settings.json` без поля `Version` значение «уведомления выключены»
  могло оказаться не выбором пользователя, и карточка после снимка не появлялась вовсе. Такой файл при первом чтении
  снова включает уведомления; следующее сохранение записывает версию, и выключенные после этого уведомления
  остаются выключенными.
- **В полноэкранной игре — показать после выхода из неё**: карточка не всплывает поверх игры.

## Редактор снимка
Открывается тремя путями: кнопка «Редактировать» (`E`) на панели под выделением, значение «открыть редактор» в
настройке «После снимка» или кнопка «Редактировать» в уведомлении. В первых двух случаях снимок ещё нигде не
сохранён; из уведомления открывается файл, причём редактор не держит его занятым. Окно появляется на мониторе,
где сделан снимок, и работает в фоновом процессе, так что закрытие окна программы его не трогает.

| Инструмент | Клавиша | Что делает |
|---|---|---|
| Выбор | `V` | щелчок выбирает фигуру, перетаскивание двигает, ручки меняют размер, двойной щелчок по тексту — править его |
| Карандаш, маркер | `P`, `H` | рисунок от руки, маркер полупрозрачный; с `Shift` — прямая |
| Линия, стрелка | `L`, `A` | с `Shift` — шаг 45° |
| Прямоугольник, эллипс | `R`, `O` | с `Shift` — квадрат или круг |
| Номер шага | `N` | щелчок ставит кружок со следующим номером: 1, 2, 3… |
| Текст | `T` | `Enter` — готово, `Shift+Enter` — новая строка, `Esc` — отмена |
| Размытие, пикселизация | `B`, `X` | скрыть пароль, номер карты, лицо |
| Обрезка | `C` | выделить, что оставить; `Enter` или двойной щелчок — обрезать |

- **Размытие и пикселизация** впекаются в сохранённый файл: исходных пикселей под областью в нём не остаётся.
  Пока снимок открыт в редакторе, область можно сдвинуть или удалить.
- **Цвет** — палитра на панели или «Другой цвет…»; **толщина** — три кнопки; **заливка** (`F`) закрашивает
  прямоугольник и эллипс, а под текстом рисует подложку; `A−` / `A+` — размер текста. Если выбрана фигура, всё
  это меняет её. Выбранные цвет, толщина, размер текста, заливка и инструмент запоминаются до следующего раза.
- **Поворот** влево и вправо — кнопками на панели.
- **Отмена** — `Ctrl+Z`, **повтор** — `Ctrl+Y` или `Ctrl+Shift+Z`; обрезка и поворот тоже отменяются.
  `Delete` удаляет выбранную фигуру, стрелки двигают её на 1 px (`Shift` — на 10).
- **Масштаб**: `Ctrl`+колесо, `Ctrl+0` — по окну, `Ctrl+1` — 100 %, `Ctrl` `+` / `−`; щелчок по проценту в строке
  состояния переключает «по окну» и 100 %. Сдвиг — средней кнопкой мыши или с зажатым пробелом, колесо
  прокручивает (`Shift`+колесо — по горизонтали).
- **Копировать** (`Ctrl+C`) кладёт в буфер снимок вместе с пометками.
- **Сохранить** (`Ctrl+S`). Новый снимок сохраняется в папку снимков по шаблону имени, как обычный. Если снимок
  открыт из файла, редактор один раз спрашивает, заменить ли его: новый файл сначала пишется рядом, прежний
  уходит в Корзину, и только потом новый встаёт на его место. «Нет» — сохранить под другим именем.
  **Сохранить как…** (`Ctrl+Shift+S`) — PNG или JPG в любое место. **Папка** показывает файл в Проводнике, а
  несохранённый снимок — папку снимков.
- При закрытии окна с несохранёнными изменениями редактор предлагает их сохранить. Кнопка «Остановить» на вкладке
  задаёт этот вопрос в каждом открытом редакторе; «Отмена» в любом из них оставляет фоновый процесс работать.

## Где данные
Настройки модуля отдельно от основных — в `%APPDATA%\SysDeck\capture\`: `settings.json`,
`status.json` (pid, права и состояние сочетаний работающего процесса — по нему вкладка показывает статус),
`recording.txt` (путь идущей записи; остался после процесса — запись оборвалась и будет восстановлена),
`video-encoders.cache` (результат пробного кодирования, чтобы не повторять его при каждом старте) и свой
`crash.log`. Видео по умолчанию сохраняются в «Видео\Captures». Кнопка «Папка данных» внизу вкладки открывает эту папку. Подробнее — в
[Данные и права](data-and-rights.md).

## Совместимость
Windows 10 и 11 на любом компьютере: всё, что зависит от версии системы, проверяется при запуске. Значки
кнопок берутся из шрифта Segoe MDL2 Assets, а если его нет, вместо них показывается текст. Видео пишется через
Windows.Graphics.Capture (Windows 10 1903 и новее); где его нет, экран пишется через Desktop Duplication, а запись
отдельного окна недоступна.
