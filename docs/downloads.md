# Загрузки

Вкладка «Загрузки»: очередь файлов из интернета с докачкой, ограничением скорости, условиями запуска, проверкой
готового файла и переносом скачанного.

[← Обзор](../README.md) · [Все разделы руководства](README.md) · [🇬🇧 English](downloads.en.md)

> Модуль развивается по этапам. Сейчас работают движок, фоновый процесс, эта вкладка, перехват загрузок из Chrome,
> Edge, Яндекс Браузера и Firefox через расширение и собственный клиент BitTorrent. Видео со страниц появится следующим
> этапом.

## Фоновый процесс
Качает не окно, а отдельный процесс того же exe (`WindowsProcessCleaner.exe --downloads`), поэтому загрузки идут и
при закрытом окне программы. Он работает **без прав администратора**, даже если окно запущено с ними: скачанные
файлы должны принадлежать вам, а не администратору.

- Процесс **запускается по требованию** — первым действием над загрузками («Добавить», «Продолжить» и т. п.).
  Открытая вкладка и смена настроек его не поднимают: пока его нет, список читается с диска.
- Когда качать и раздавать нечего и вкладка не открыта, процесс **закрывается сам через минуту**.
- Строка над списком показывает, работает ли процесс, сколько загрузок идёт (торренты тоже), сколько торрентов
  раздаётся, общую скорость, лимит и что держит
  очередь (расписание, батарея, лимитная сеть, простой).
- Если в очереди остались незавершённые загрузки, процесс поднимется при входе в Windows (значение в
  `HKCU\...\Run`, пока очередь не опустеет; выключается в настройках).
- **Остановить процесс** — в настройках. Скачанное сохраняется, загрузки продолжатся при следующем запуске.

## Добавить загрузку
- **Добавить…** открывает диалог. Ссылки — по одной в строке, только `http` и `https`. Строки без ссылки
  показываются как пропущенные, повторы убираются.
- **Вставить ссылки** и `Ctrl+V` в списке берут ссылки из буфера обмена. Буфер читается только по этому действию,
  программа за ним не следит.
- В список можно **перетащить** ссылку из браузера или ярлык интернета (`.url`).

В диалоге:
- **Папка** — пусто означает «по правилам настроек»; под полем видно, куда попадёт файл и сколько там свободно
  (меньше 1 ГБ — предупреждение). «Последняя» подставляет папку прошлого добавления.
- **Имя файла**, **ожидаемый хеш** (`sha256:…`, `sha1:…`, `md5:…` или просто шестнадцатеричная строка) и
  **зеркала** — только для одной ссылки.
- **Начать**: сразу, на паузе, через N минут, в указанное время или когда компьютер простаивает.
- **Лимит скорости**, **число потоков** и **приоритет** этой загрузки.

Если ссылка уже есть в списке, программа спросит, скачать ли её ещё раз; новый файл получит другое имя.

## Торренты
Торренты качает тот же фоновый процесс, своим клиентом BitTorrent, без сторонних программ. Торрент стоит в общем
списке рядом с обычными загрузками.

Добавить торрент:
- **Торрент…** на панели — выбрать файл `.torrent`.
- `Ctrl+V` или перетаскивание в список: magnet-ссылки из текста и файлы `.torrent`. Одна и та же раздача, вставленная
  дважды с разными трекерами, добавляется один раз.
- Двойной щелчок по `.torrent` или magnet-ссылка в браузере, если программа назначена для них в настройках.

Диалог торрента:
- Список файлов с флажками и размерами, **Отметить все / Снять все**. У magnet-ссылки список придёт от пиров, поэтому
  сначала качается всё; ненужные файлы потом снимаются на вкладке «Файлы».
- **Папка** и свободное место на диске рядом с объёмом выбранных файлов. Если места не хватит, это видно сразу.
- **Имя папки раздачи** (у торрента из одного файла — имя файла).
- Если в папке уже лежат данные этой раздачи, флажок **проверить их, докачать недостающее и раздавать** берёт их
  вместо новой копии.
- **Начать** сразу или на паузе, **приоритет**, **качать куски по порядку**: видео можно смотреть, пока оно
  качается, но раздача от этого медленнее.

Без диалога, с настройками по умолчанию, торрентом становятся:
- файл `.torrent`, скачанный обычной загрузкой. Сама запись загрузки остаётся в списке с отметкой в журнале;
- файл `.torrent`, скачанный браузером, если программа не смогла забрать его у браузера;
- новый файл `.torrent` в **папке наблюдения**.

Тот же торрент второй раз не добавляется. Файл, который оказался страницей сайта с именем `.torrent`, остаётся
обычным файлом. Папка наблюдения просматривается раз в несколько секунд, пока работает фоновый процесс, и только
верхний уровень. Файл, который ещё пишется, ждёт следующего прохода. Торрент, убранный из списка, из папки не
возвращается, в том числе после перезапуска. Если включено **Убирать файл .torrent после добавления**, файл уходит в
Корзину, а копию браузера удаляет сам браузер. Содержимое торрента программа хранит у себя.

В списке у торрента свои состояния: **проверка данных · N %**, **качается · пиры (сиды) · скорость отдачи**,
**раздаётся**. В меню записи вместо команд одной ссылки:
- **Проверить данные**, **Запросить пиров у трекеров**, **Качать по порядку**;
- **Копировать magnet-ссылку**;
- **Раздавать снова** у раздачи, остановленной по рейтингу или времени;
- **Новая версия раздачи** и, когда она найдена, **Обновить раздачу…** — см. ниже.

«Скачать заново», смена ссылки, зеркала и перенос торренту недоступны.

### Новая версия раздачи
Раздачу на трекере перезаливают: добавили серии, заменили файл. Старая перестаёт раздаваться, у новой другой
info-hash. Программа находит новую версию и переводит на неё ту же запись: скачанное остаётся на месте,
докачивается только изменённое.

Ссылку на тему программа берёт из самого `.torrent` (поле комментария или сайта издателя) и показывает её в карточке
строкой **Тема раздачи**. Сама проверяет только rutracker, через его открытый API `api.rutracker.cc`, без входа на
сайт:
- раз в 6 часов, пока включено **Проверять новые версии раздач rutracker раз в 6 часов**;
- сразу, если трекер ответил «Torrent not registered», но не чаще раза в час на раздачу.

Для других трекеров (nnmclub, kinozal, rutor и т. п.) новую версию берут файлом со страницы темы.

Когда новая версия найдена:
- приходит уведомление, в списке к состоянию добавляется **есть новая версия**, в карточке — строка **Новая версия**;
- программа запрашивает у пиров метаданные новой версии через трекеры прежней, с тем же ключом доступа. В папку
  загрузки при этом ничего не пишется. Если пиров нет, повтор через час;
- сама раздача не меняется, пока вы не нажмёте **Обновить**.

В меню записи, подменю **Новая версия раздачи**:
- **Проверить на rutracker сейчас** — только у раздач с темой rutracker;
- **Взять из файла .torrent…** — любой трекер, тема не сверяется. Файл той же версии программа отклонит, а что
  станет с файлами, видно в окне до обновления;
- **Открыть страницу темы** — в браузере по умолчанию.

Если открыть `.torrent` той же темы, что у раздачи в списке, но с другим info-hash, программа сначала спросит:
**Да** — обновить эту раздачу, **Нет** — добавить отдельной загрузкой. Такой файл из папки наблюдения или скачанный
обычной загрузкой становится новой версией без вопроса, но и он ничего не заменяет до кнопки.

**Обновить раздачу…** открывает окно «Новая версия раздачи». В нём info-hash, итог по файлам (остаются, переносятся,
изменены, новые, в Корзину) и список «что будет» с каждым файлом. Кнопки:
- **Обновить** — останавливает раздачу, отправляет в Корзину файлы, которых в новой версии нет, переносит
  переименованные и проверяет данные хешем новой версии. Докачиваются только изменённые и новые файлы, снятые
  флажки «не качать» сохраняются, имя папки не меняется;
- **Не обновлять** — эта версия больше не предлагается, следующая будет;
- **Закрыть** — ничего не меняет;
- **Открыть страницу темы** и **Из файла .torrent…** — если нужна другая версия.

Если метаданных ещё нет, окно говорит об этом, и **Обновить** недоступна. Обновить нельзя и в таких случаях
(причину окно пишет над кнопками):
- это та же версия;
- раздача стала папкой или, наоборот, одним файлом — такую добавляют отдельно;
- новая версия только BitTorrent v2;
- на месте новых файлов лежат чужие файлы.

Пока идёт обновление, запись нельзя запустить, проверить или удалить. Если процесс завершился на полпути, при
следующем запуске он доводит обновление до конца.

## Видео
Видео в интернете почти никогда не лежит одним файлом: страница отдаёт плейлист, а сам ролик нарезан на сотни кусков,
которые нужно скачать и склеить обратно. Программа умеет это сама.

Что можно скачать:
- **потоки HLS** (`.m3u8`) и **DASH** (`.mpd`), включая живые трансляции;
- **прямые ссылки** на видео- и аудиофайлы;
- **страницы видеосайтов** — для них нужен `yt-dlp` (см. ниже).

Как добавить:
- в диалоге **Добавить…** поставить галку **«Скачать как видео»**. Для ссылок на `.m3u8` и `.mpd` она ставится сама;
- из браузера — расширение показывает найденные на странице потоки в своём окошке, оттуда их можно отдать программе.

Что происходит дальше: программа разбирает плейлист, выбирает качество, качает куски (при обрыве продолжает с того же
места, а не сначала), затем склеивает их в один файл и проверяет, что он читается. Пока идёт запись, в списке видно
не байты, а **куски и записанное время** — размер файла станет известен только после склейки.

В меню записи (правая кнопка) появляются два пункта:
- **Смотреть сейчас** — открыть недокачанный файл в проигрывателе, не дожидаясь конца;
- **Остановить запись** — для трансляции: докачать начатые куски и собрать файл. У трансляции своего конца нет,
  её всегда останавливает человек.

Субтитры сохраняются отдельными файлами рядом с видео (`фильм.ru.vtt`, `фильм.ru.srt`), в сам ролик они не вшиваются.

### yt-dlp и Deno
Страницы видеосайтов разбирает `yt-dlp` — отдельная программа с открытым исходным кодом. Вместе с ней ставится `Deno`:
некоторые сайты требуют выполнить свой JavaScript, чтобы выдать ссылку на видео.

Ни та, ни другая **не входят в состав программы и не скачиваются сами**. Их ставит только кнопка
**«Установить yt-dlp…»** в настройках загрузок, разделе «Видео». Перед первым запуском проверяется контрольная сумма
скачанного файла; не совпала — файл не запускается, а прежняя версия остаётся на месте. Без них потоки HLS/DASH и
прямые ссылки работают, а страницы видеосайтов — нет.

## Загрузки из браузера
Расширение «Windows Process Cleaner — загрузки» передаёт программе загрузки, начатые в Chrome, Edge, Яндекс Браузере и
Firefox. Браузер и программа общаются через native messaging: браузер сам запускает `WindowsProcessCleaner.exe` и
обменивается с ним сообщениями на этом компьютере, в сеть ничего не уходит. Что читает расширение, описано в
[Конфиденциальности расширения](extension-privacy.md).

Подключение:
1. **Настройки загрузок → Браузеры → Связь с браузерами** (включено по умолчанию). Программа записывает в `HKCU` ключи
   `NativeMessagingHosts\org.wpc.downloads` для Chrome, Edge и Firefox; выключение сразу их удаляет. Пока связь
   включена, фоновый процесс при каждом запуске проверяет, что ключи ведут к текущему exe.
2. Выберите браузер в списке и нажмите **Установить расширение…**. Программа распакует расширение в
   `%APPDATA%\WindowsProcessCleaner\downloads\extension\` и откроет страницу расширений браузера. Шаги показаны под
   списком:
   - Chrome, Edge, Яндекс Браузер: включить «Режим разработчика», нажать «Загрузить распакованное» и выбрать папку;
   - Firefox: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение…» → `manifest.json` из папки.
     Временное дополнение работает до перезапуска Firefox; постоянно ставится только подписанный файл из каталога
     дополнений Mozilla.

   Пошагово, по каждому браузеру (включая Opera, Brave и Vivaldi), с разбором частых ошибок —
   в [Установке расширения вручную](extension-install.md).
3. Колонка «Расширение» покажет «на связи» со временем последнего подключения и версией расширения.

Связь регистрирует только копия программы со стандартной папкой данных. У портативной копии и копии с `WPC_DATA_DIR`
раздел пишет, что браузеры с ней не связываются.

Что происходит с загрузкой:
- Когда вы начинаете загрузку, расширение показывает её программе: в Chrome, Edge и Яндекс Браузере — до того, как
  браузер начнёт писать файл, в Firefox — сразу после начала. Программа одним запросом с cookies сайта проверяет,
  отдаёт ли сервер ей тот же файл.
- Если отдаёт, загрузка встаёт в очередь программы и начинается сразу, а браузер свою отменяет и убирает из списка
  (Firefox удаляет и начатый файл). Появляется уведомление **«Загрузка перехвачена»** с кнопками **Открыть загрузки**
  и **Отдать браузеру**. «Отдать браузеру» убирает загрузку из списка программы (недокачанное — в Корзину), и браузер
  качает файл заново сам. Кнопка работает, пока загрузка не завершена.
- Загрузка остаётся браузеру, если:
  - перехват выключен в настройках или в окне расширения;
  - сайт или расширение файла есть в списках «Не забирать…»;
  - окно приватное, а «И в режиме инкогнито» не включено;
  - при щелчке зажат `Alt`;
  - ссылка не `http` и не `https`;
  - сервер отдаёт программе не тот файл: страницу входа, ошибку, другой размер;
  - программа не ответила за 5 секунд.

  Браузер в этих случаях ничего не теряет: его загрузка идёт как обычно. Так же браузеру остаётся торрент-файл, который
  сервер программе не отдаёт.
- Cookies сайта программа держит только в памяти фонового процесса. Если после его перезапуска сервер снова требует
  вход, программа показывает «Нужна новая ссылка» и, пока браузер с расширением открыт, сама запрашивает у него свежие
  cookies этого сайта.

Окно расширения (кнопка на панели браузера): состояние связи, переключатель **Перехватывать загрузки** (тот же, что
«Забирать у браузера все загрузки» в настройках), **Не перехватывать на этом сайте** (добавляет сайт в исключения
программы), число идущих и ждущих загрузок, скорость и **Открыть загрузки**. Если у расширения нет доступа ко всем
сайтам, окно предложит **Разрешить**: без этого доступа cookies не передаются и сайты со входом отдают файл только
браузеру.

В контекстном меню страницы — **Скачать ссылку**, **изображение**, **все ссылки** и **выделенные ссылки через Windows
Process Cleaner**: выбранные ссылки встают в очередь программы вместе с cookies сайта.

## Список
- Колонки: имя, размер, прогресс, скорость, сколько осталось, состояние, источник, папка, когда добавлено. Под
  полосой прогресса тонкая карта показывает, какие части файла уже скачаны.
- Фильтры над списком: **Все / Качаются / Ждут / На паузе / Готовые / Ошибки** с числом записей, а также тип
  файла и источник: вручную, Chrome, Edge, Яндекс Браузер, Firefox, другой Chromium или папка наблюдения
  торрентов. Выбор фильтров, ширины колонок и высота карточки запоминаются.
- Клавиши: `Enter` открывает готовый файл, `Space` ставит паузу или продолжает, `Delete` убирает запись из списка,
  `Shift+Delete` удаляет вместе с файлом, `Ctrl+A` выделяет всё.
- **Пауза / Продолжить / Удалить** работают с выделенными записями, **Всё на паузу / Продолжить всё** — со всей
  очередью. Режим **Скорость** переключает обычный лимит, тихий («не мешать сети») и работу без ограничений.

Контекстное меню записи:
- **Открыть файл**, **Показать в папке**, **Копировать ссылку**.
- **Скачать заново с нуля** удаляет скачанную часть после вопроса.
- **Обновить ссылку**: для загрузки с истёкшей ссылкой. Скачанное сохраняется, если сервер отдаёт файл того же
  размера.
- **Добавить зеркало**: запасная ссылка на тот же файл.
- **Ограничить скорость**, **Приоритет**, **Только когда ПК простаивает**, **Отложить** на 10 минут, час, 3 или
  8 часов.
- **Переместить в… / Копировать в… / Отменить перенос.** Перенос идёт в фоне. На другой диск файл сначала
  копируется и сверяется по SHA-256, и только потом исходник уходит в Корзину. Прерванный перенос продолжается при
  следующем запуске. Метка «из интернета» переезжает вместе с файлом.
- **Посчитать хеш** MD5, SHA-1 или SHA-256. Результат копируется в буфер и сравнивается с ожидаемым, если он был
  указан.
- **Удалить из списка**: файлы остаются на диске. **Удалить вместе с файлом** отправляет файл (у недокачанных —
  частичный `.wpcpart`) в Корзину. На томе без Корзины файл не удаляется вовсе.
- **Очистить историю**: убирает записи о готовых загрузках старше 30 дней, чьих файлов уже нет, или все готовые.
  Файлы не трогаются.

## Открытие программ
Файл, который может выполнить код (`.exe`, `.msi`, `.bat`, `.ps1` и подобные), без вопроса не открывается. Сначала
программа проверяет цифровую подпись (без похода в сеть) и показывает:
- издателя и состояние подписи: подписан, без подписи, подпись недействительна (файл изменён после подписи) или
  не доверена;
- сайт, откуда файл скачан;
- метку «из интернета».

Кнопка по умолчанию — «Нет». Сам файл запускает Windows, поэтому SmartScreen и предупреждение о файле из интернета
срабатывают как обычно.

## Карточка загрузки
Под списком — подробности выделенной записи:
- **Обзор**: состояние, размер, путь к файлу, сайт, лимит, приоритет, попытки, последняя ошибка, ожидаемый хеш. У
  готовой программы показаны подпись и метка «из интернета».
- **Сегменты**: карта файла и таблица частей. Видно, сколько скачано и сколько уже надёжно сброшено на диск (с
  этого места пойдёт докачка после сбоя).
- **Сеть**: ссылка, переадресации, зеркала, откуда пришла ссылка, User-Agent, поддержка докачки, ETag и
  Last-Modified. Токены в ссылках скрыты. Cookies не показываются: только «есть» или «нет».
- **Журнал**: события загрузки, новые сверху.

У торрента вместо «Сегментов» и «Сети» свои вкладки:
- **Обзор** добавляет принятое и отданное, рейтинг, пиров и сидов, число кусков и карту проверенных, доступность
  раздачи, info-hash, формат (v1, v2 или гибридный), порт и открыты ли входящие. Если в торренте есть ссылка на
  тему — строки **Тема раздачи** и **Новая версия** (есть, нет с временем проверки, ещё не проверялась).
- **Файлы**: путь, размер, сколько готово и приоритет. В контекстном меню — **Качать в первую очередь**, **Качать**,
  **Не качать**.
- **Пиры**: адрес, клиент, сколько у пира есть, скорость приёма и отдачи, откуда пир (трекер, DHT, обмен пирами,
  локальная сеть, входящее) и шифрование.
- **Трекеры**: состояние, сиды и личи, сколько пиров прислал трекер, когда следующий запрос и сообщение трекера.

Пока фоновый процесс не запущен, карточка торрента строится из его файла: файлы и размеры видны, прогресса нет.

`Ctrl+C` копирует выделенные строки карточки.

## Настройки
Кнопка **Настройки загрузок** открывает их на месте списка. Изменения сохраняются сами. Если процесс работает, он
применяет их сразу. Если нет, они записываются в файл, и очередь от этого не запускается.

- **Куда сохранять**: папка по умолчанию («Загрузки» Windows) и правила по сайту или по расширению. Сначала
  проверяются правила по сайту, потом по расширению, в каждой группе сверху вниз. `example.com` означает только этот
  сайт, `*.example.com` добавляет все поддомены. В системные папки загрузки не пишутся.
- **Спрашивать папку** (включено по умолчанию): перехваченная у браузера загрузка сначала показывает окно
  **«Куда скачивать?»**. В списке — папка из настроек, «Загрузки» Windows и все запомненные места; **«Обзор…»**
  добавляет новое, **«Убрать из списка»** (или `Delete`) убирает лишнее из запомненных сразу и насовсем.
  Флажок **«Запомнить эту папку»** пополняет этот список, **«Больше не спрашивать»** выключает вопрос совсем.
  Пока ответа нет, загрузка стоит и не скачала ни байта; окно, закрытое без ответа, оставляет её на паузе с
  пометкой «папка не выбрана» — продолжить можно кнопкой **Продолжить** или выбрав папку через **Переместить в…**.
- **Скорость**: режим, общий лимит, лимит тихого режима (по умолчанию 256 КБ/с), отдельный ночной лимит.
- **Очередь и соединения**:
  - одновременно до 3 загрузок и до 2 с одного сайта;
  - до 4 потоков на файл и 8 соединений на сервер;
  - файлы меньше 5 МБ идут вне очереди;
  - после сбоя до 8 повторов с паузой до 5 минут.
- **Когда качать**:
  - расписание по дням и часам;
  - вся очередь только при простое (5 минут без ввода, процессор ниже 30 %, нет полноэкранной игры или фильма);
  - пауза на лимитном подключении и от батареи;
  - запрет сна, пока идёт загрузка.
- **Безопасность**: метка «из интернета», проверка Защитником Windows, свой User-Agent.
- **Браузеры**: связь с браузерами, перехват всех загрузок, приватные окна, сайты и расширения файлов, которые остаются
  браузеру, список браузеров и установка расширения. Подробнее — в [Загрузках из браузера](#загрузки-из-браузера).
- **Видео**:
  - **Качество** — не выше выбранного (по умолчанию «лучшее из доступного»); нет такого — берётся ближайшее снизу.
    Прерванная запись продолжается в том качестве, с которого начата;
  - **Файл** — контейнер: «по дорожкам» (MP4, а для дорожек WebM — WebM), MP4, WebM, M4A или MP3 (два последних —
    только звук);
  - **Скачивать субтитры отдельными файлами рядом с видео**;
  - **Установить yt-dlp…** и **Проверить обновление**, **Держать yt-dlp свежим** (проверка не чаще раза в сутки).
    Подробнее — в [Видео](#видео).
- **Фоновый процесс и уведомления**: продолжать после входа в Windows, уведомления о готовой загрузке и об ошибке.
  Уведомление показывает кнопку «Папка»; щелчок по нему самому файл не открывает.
- **Торренты**:
  - **Разрешить входящие…** один раз спрашивает права администратора и добавляет в брандмауэр Windows правило
    `Windows Process Cleaner (BitTorrent)` только для этой программы. Без входящих торрент тоже качает и раздаёт, но
    только пирам, к которым подключился сам. **Закрыть входящие** перестаёт слушать порт; правило остаётся, но без
    открытого порта ничего не пропускает. Строка над кнопками показывает, что сейчас с брандмауэром;
  - открытие порта на роутере (UPnP / NAT-PMP), пока входящие разрешены;
  - порт (0 — свободный выбирается при первом запуске и запоминается) и шифрование: предпочитать, только шифрованные
    соединения или без шифрования;
  - DHT, обмен пирами и поиск в локальной сети. У закрытых торрентов они выключены всегда;
  - сколько торрентов качается одновременно (по умолчанию 3, раздачи не считаются), лимит отдачи, соединений всего и
    на торрент, слоты отдачи. Приём подчиняется общему лимиту загрузок;
  - раздавать после загрузки и когда остановить раздачу: по рейтингу или через N минут;
  - папка наблюдения и **Убирать файл .torrent после добавления**, см. [Торренты](#торренты);
  - **Проверять новые версии раздач rutracker раз в 6 часов** (включено по умолчанию), см.
    [Новая версия раздачи](#новая-версия-раздачи);
  - **Открывать файлы .torrent** и **magnet-ссылки этой программой**. Записи — только в `HKCU`, при выключении
    возвращается прежнее приложение. Если в Windows уже выбрано другое приложение, программа не перебивает этот
    выбор и предлагает кнопку **Приложения по умолчанию…**.
- **История**: те же три варианта очистки, что в меню.

## Где данные
Всё — в `%APPDATA%\WindowsProcessCleaner\downloads\`: `settings.json`, `index.json` (порядок очереди), по файлу
на загрузку в `items\` и журнал процесса `engine.log`. Cookies из браузера на диск не пишутся никогда. Недокачанный
файл лежит в своей папке с окончанием `.wpcpart`. Связь с браузерами добавляет `nmh\` (манифесты для браузеров),
`extension\` (распакованное расширение) и `bridge-<браузер>.json` (когда расширение подключалось и его версия).
Недокачанное видео лежит рядом с будущим файлом в папке с окончанием `.wpcmedia`: куски и журнал, по которому запись
продолжается после обрыва; после склейки папка удаляется. `yt-dlp.exe` и `deno.exe` (если их ставили) — в `tools\`,
там же `tools.json` с их контрольными суммами: изменённый после установки файл программа не запускает.
Торренты хранят в `torrents\` копию файла торрента (`<info-hash>.torrent`), состояние кусков для быстрого
продолжения (`<info-hash>.resume.json`) и `watch-seen.txt` — какие файлы папки наблюдения уже обработаны. Новая
версия раздачи ждёт там же в `update-<id>.torrent`, незаконченное обновление — в `update-<id>.json` (по нему процесс
доводит обновление после сбоя), а `rutracker.json` хранит последние ответы rutracker, чтобы не спрашивать лишний раз.

Копия программы со своей папкой данных (портативная, перенаправленная через `WPC_DATA_DIR`) получает свой
фоновый процесс и свой канал. Она не видит и не трогает очередь основной программы. Подробнее — в
[Данные и права](data-and-rights.md).
