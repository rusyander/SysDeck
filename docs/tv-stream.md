# ТВ-трансляция

[🇬🇧 English](tv-stream.en.md) · [Руководство](README.md)

Видео с компьютера на телевизоре Hisense (VIDAA) по домашней сети: без проводов, флешек и DLNA. Компьютер сам
становится небольшим видеосервером, телевизор открывает его в приложении **Media Station X** или во встроенном
браузере. Папки с фильмами выбираются в окне программы; на телевизоре каждая папка — отдельный раздел с превью
и «Продолжить просмотр».

То же окно есть в двух видах:

- **в SysDeck** — страница **«ТВ-трансляция»** в меню слева (после «Загрузок»). Туда же ведут кнопка
  «📺 ТВ-трансляция» на вкладке «Инструменты» (раздел «Медиа») и пункт с тем же названием в меню значка в трее.
  Сервер работает, пока работает SysDeck, даже если окно закрыто или открыта другая страница;
- **отдельной программой PC Stream** (`PcStream.exe`) — для компьютера без SysDeck. Живёт в трее, может запускаться
  вместе с Windows.

## Как подключить телевизор

Кнопка **«Как подключить ТВ — по шагам»** открывает окно, которое ведёт по всем шагам и само проверяет каждый:
зелёная галочка — шаг сделан. При первом открытии «ТВ-трансляции» оно появляется само. В PC Stream его же
открывает пункт «Как подключить телевизор…» в меню значка.

| Шаг | Что делать | Что проверяет окно |
|---|---|---|
| 1. Папки | «+ Добавить папку…» или перетащить папку в окно | сколько папок добавлено |
| 2. Трансляция | «▶ Включить трансляцию» | что сервер слушает порт |
| 3. Брандмауэр | «Разрешить в брандмауэре», один раз | пропускает ли Windows входящие на порт в текущей сети |
| 4. ffmpeg | «Скачать ffmpeg» — нужен для MKV, AVI и превью | найден ли ffmpeg |
| 5. Media Station X | на телевизоре: кнопка VIDAA или App Store → найти и установить **Media Station X** | — |
| 6. Адрес в MSX | в MSX: Settings → Start Parameter → Setup → ввести адрес **без http://**, подтвердить | показывает настоящий адрес крупно |
| 7. Смотреть | открыть MSX: слева появятся папки с компьютера | когда телевизор последний раз заходил |
| 8. Запасной вариант | браузер телевизора, адрес вместе с `http://` | — |

Адрес выглядит как `192.168.0.101:8090`: IP компьютера в домашней сети и порт. Кнопки рядом с адресом в главном окне:
«Копировать адрес», «Открыть как на ТВ» (то же, что увидит телевизор, в браузере компьютера) и «Разрешить
в брандмауэре». Печатная инструкция с теми же шагами — кнопка «Инструкция (PDF)» в окне шагов.

## Что играет и как

| Файлы | Как отдаются |
|---|---|
| MP4, M4V, WebM, MOV | напрямую, с мгновенной перемоткой |
| MKV, AVI, TS, M2TS, WMV, FLV, MPG, 3GP, VOB | перекодируются на лету через ffmpeg; первые секунды уходят на запуск |

Без ffmpeg работают только файлы из первой строки и нет превью кадров на плитках. Карточка «Сейчас смотрят» показывает,
какое устройство что смотрит и в каком режиме: «напрямую» или «перекодирование».

## ffmpeg одной кнопкой

«Скачать ffmpeg» скачивает официальную сборку *essentials* от gyan.dev (~115 МБ) и кладёт `ffmpeg.exe`
и `ffprobe.exe` в папку `ffmpeg` внутри папки данных программы. Ничего не устанавливается, прав администратора
не нужно.

- Источник — релизы той же сборки на GitHub (`GyanD/codexffmpeg`): они качаются в десятки раз быстрее сайта
  gyan.dev. Если GitHub недоступен, программа берёт архив с gyan.dev.
- Перед распаковкой архив сверяется по SHA-256: для GitHub сумма берётся из описания релиза, для gyan.dev — из его
  файла `.sha256`. При несовпадении архив отбрасывается, а прежний ffmpeg, если был, остаётся на месте.
- Пока идёт загрузка, строка ffmpeg показывает прогресс, а кнопка становится «Отменить». Недокачанные файлы удаляются.

Если ffmpeg уже есть в системе (в `PATH` или установлен через winget), программа найдёт его сама, но свою копию
проверяет первой.

## Брандмауэр

Без разрешения Windows не пустит телевизор к компьютеру. Кнопка «Разрешить в брандмауэре» один раз спрашивает права
администратора и делает две вещи:

1. снимает **запрещающие** правила для этой программы — их Windows создаёт, если в её окне «Разрешить доступ»
   нажать «Отмена», и они сильнее любого разрешения;
2. добавляет правило **«PC Stream TCP <порт>»**: входящие TCP на порт трансляции, только с адресов своей подсети
   (`LocalSubnet`), в любом профиле сети.

Правило не привязано к профилю «Частная» намеренно: домашнюю сеть Windows часто помечает «Общедоступной», и тогда
правило для частной сети не сработало бы. Открыт порт всё равно только устройствам своей подсети. Чужие правила
и разрешения других программ кнопка не трогает. Состояние окно шагов читает без прав администратора и показывает
имя и тип сети.

## Безопасность

- Сервер отвечает только устройствам локальной сети; запрос с внешнего адреса получает отказ 403.
- Видны только добавленные папки. Путь вида `../` за пределы папки отвергается.
- Файлы только читаются, ничего не копируется и не загружается на компьютер.
- Сервер выключается кнопкой «Выключить трансляцию» или вместе с программой («Выход» в меню значка).

## Настройки

| Настройка | Что делает |
|---|---|
| Порт | по умолчанию 8090; после смены нажать «Применить» и ввести новый адрес в телевизоре |
| Включать трансляцию при запуске программы | сервер поднимается сам |
| Превью кадров на плитках | кадр с 10 % длины видео через ffmpeg; делается один раз и хранится в кеше |
| Запускать PC Stream вместе с Windows | только в PC Stream: запуск в трее при входе в Windows |

Настройки — файл `tvstream.json` в папке данных: у SysDeck это `%APPDATA%\SysDeck\`
(см. [Данные и права](data-and-rights.md)), у PC Stream — `%APPDATA%\PcStream\`. Там же папка `ffmpeg`.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Телевизор не видит сервер | индикатор зелёный? обе машины в одной сети? строка «Брандмауэр» в окне шагов |
| Адрес перестал работать | роутер выдал компьютеру новый IP: новый адрес в окне, ввести его в MSX заново; чтобы не менялся — закрепить IP в роутере |
| «Порт … уже занят другой программой» | выбрать другой порт в настройках и ввести новый адрес в телевизоре |
| MKV не открывается | нет ffmpeg — «Скачать ffmpeg» |
| Нет картинки, только звук | редкий кодек: попробовать браузер телевизора или сконвертировать файл в MP4 |
